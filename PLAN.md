# Implementation plan - Asset 360

1. **Contracts:** Preserve the React/TypeScript/Aura/Flows scaffold. Inspect installed SDK declarations and query official Cognite Docs MCP. Define a narrow injected AssetService and safe runtime instance parsers.
2. **Test CDF reads first:** Assert ranked text search plus externalId prefix lookup, batched parent/type hydration, exact space/externalId filters, paginated related lists, date ordering and rejected API calls. A list of direct relations cannot be traversed in reverse: filter the owning view on assets. Datapoints use instanceId; latest retrieval precedes bounded aggregated history reads. Resolve file links on demand.
3. **Shared state:** A provider owns host-synchronized navigation (asset, query, selected series, range, open detail). A stateless useInvestigationViewModel composes shared storage and independent query hooks. Disable polling/focus refetch and use bounded retry. Inject storage and host dependencies. Bound local recent assets to 10; never store tokens or file links.
4. **UI:** Aura combobox, buttons, cards, tables, feedback, dialogs. Search and recent assets lead to an asset identity header and independent series/activity/document panels. Use an available chart primitive, or an accessible SVG plus data table if Aura cannot cover historical plotting. Keep mixed units on separate scales and failures local. Add root and panel error boundaries.
5. **Verification:** Behavior tests cover search/select, no initial series, stale-data anchoring, manual refresh, empty points, 403s, previews, recent history and malformed state. Run tests, build and lint; inspect the browser. Run flows-code-review and flows-design-review, fix Must Fix findings and record live checks separately from test fixtures.
6. **Live acceptance:** Open local development inside the publicdata Fusion host for user authentication. Validate a real asset, series and file where present. Record any permission/authentication blocker with exact next steps. Do not claim certification or live-data validation based only on local tests. Deployment and formal certification remain distinct actions.
